## Genjutsu template (motion transfer)
Order matters. Lead with the background swap, lock the motion, then define identity top to bottom.

```
COMPLETELY REPLACE THE BACKGROUND: <setting>. NO text, NO logos.
Keep the exact <dance moves / head movement, mouth movement while talking, facial expressions,
hand gestures>, timing and camera motion of the reference.
[If the source wears a mask/durag/beanie: REMOVE the <item> completely.]
Replace the man with Winston from the reference sheet, EXACT SAME FACE: albino, pale skin (EVERYWHERE incl.
arms, hands, legs), LEAN MUSCULAR ATHLETIC build, slim sharp jawline. NOT chubby, NOT round-faced.
HAIR: platinum curly Edgar bowl cut, straight-across curly fringe, tight waves, faded sides,
ONE pencil-thin platinum braided rat tail over his shoulder. NO dreadlocks, NO long hair.
CAP: <color> MGW baseball cap ON the whole video, worn high so the fringe shows   (or: NO HAT, bare hair)
Clear acrylic glasses with silver cross hinges ON. White-blonde goatee. Natural white teeth, NO grill.
Old-money fit: <outfit>. <prop swaps, e.g. "the bottle becomes an espresso martini in a coupe glass">.
Photoreal skin texture, natural phone video look.
```

## Fixes that worked
| Problem | Fix |
|---|---|
| Cap missing (source person bare-headed) | Attach a photo of Winston *wearing* the MGW cap as a 2nd reference + write the cap line twice |
| Wrong haircut | Describe the exact cut ("Edgar bowl cut, straight-across curly fringe..."), never "short curls at the front" |
| Readable venue sign copied | Blur/darken the sign region in the source before upload (prompt alone fails) |
| Dark arms on albino Winston | The fit reference showed another person's skin. Generate "Winston wearing the fit" with Nano Banana 2 first and use that as the reference |
| Long flowing hair from a dreadlocked dancer | Prompt helps a little; best fix is choosing short-haired sources |
| Heavy body copied from source | Prompt can't fix it. Only pick slim/athletic sources |
| Drink splash / stained clothes | Avoid sources where the person throws things or drinks from a bottle |
